# 相机与运动

相机是可读性工具，不是默认叙事手段。视觉意图先声明固定画框，编译器把它展开为完整相机边界；`emphasisIds` 只改变注意力，不参与相机求解。

## 决策顺序

当前画框无法读清必读内容时，依次尝试：

1. 精简非必要说明；
2. 调整布局与留白；
3. 折叠已经讲过的内部细节；
4. 拆成固定局部世界或使用稳定详情区；
5. 上述方式仍不合适时，才请求带理由的新画框。

不同世界重新挂载舞台，不做误导性的空间飞行。普通画框变化直接插值到目标；`viaOverview` 仅在跨远处目标且恢复空间关系确有帮助时，分两段经过世界总览。

## 运行时阶段

一个步骤的统一时序是：

```text
定位画框 → 相机稳定 → 显示讲解字幕 → 阅读停留
```

运行时规则：

- 当前边界与目标边界近似相等：直接短路，不创建动画，不增加等待；
- 转场中再次切步：取消旧动画，从当前插值帧接到新目标；
- 目录跳转、刷新恢复：目标状态完整可恢复；
- 上一步：从当前帧到前一目标，不倒放历史轨迹；
- 减少动态效果模式：直接到目标并立即进入阅读阶段；
- 自动播放：相机稳定后才开始计算 `holdMs`；
- 详情面板：一个场景内预留稳定区域，桌面在右侧、小屏在下方；
- 调整尺寸：SVG 自适应视口，不改变世界几何结构或叙事游标。

转场期间只显示简短定位提示，不显示需要阅读的新公式、长字幕或解释。仍然只有一份讲解字幕和一套步骤时序，不建立第二套字幕数据。

## 校验

编译后的相机边界和画框边界必须有限且为正尺寸。`requiredReadableIds` 必须存在、完整落在画框内，且其所属对象在使用该画框的步骤中可见。引用非默认画框时必须使用 `required_content_unreadable`、`inspect_source_detail` 或 `restore_spatial_context` 之一作为理由。

校验器对引用、隐藏、裁切和无理由更换画框报错；对固定桌面/窄屏配置下的估算字号发出警告。字号阈值是可调工程参数，不声称适用于所有设备；浏览器验证仍需检查实际 DOM/SVG 屏幕尺寸、遮挡和布局密度。
